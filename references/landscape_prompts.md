# 风景风光摄影提示词库（8 大风格）

每个风格含：风格说明 / 英文提示词模板（替换 `{location}` 为地点、`{time}` 为时间）/ 推荐参数 / 负向词。
生图前提醒用户 ImageGen 消耗额度（约 5–10 credits/张）。

---

## 1. 高山云海 Mountain Sea of Clouds
**说明**：层峦叠嶂、云雾流动，壮美空灵。
**英文模板**：
```
Photorealistic landscape of {location}, endless sea of clouds over mountain peaks, soft morning mist, dramatic depth, 24mm wide lens, f/8, high dynamic range, cinematic --ar 16:9
```

## 2. 海岸日落 Coastal Sunset
**说明**：暖色天空、海面反光、长曝光丝滑感。
**英文模板**：
```
Photorealistic coastal sunset at {location}, golden sky reflection on calm sea, silhouette of rocks, long exposure silky water, 16mm lens, f/11, warm tones --ar 3:2
```

## 3. 城市夜景 City Night
**说明**：车流光轨、霓虹、蓝调时刻。
**英文模板**：
```
Photorealistic city night panorama of {location}, light trails on highways, neon glow, blue hour, 24mm lens, f/8, long exposure, sharp --ar 16:9
```

## 4. 极简雪景 Minimal Snow
**说明**：留白、单一主体、宁静。
**英文模板**：
```
Photorealistic minimalist snow scene at {location}, vast white field, tiny lone tree, soft overcast light, negative space, 35mm lens, f/5.6, serene --ar 3:2
```

## 5. 秋色森林 Autumn Forest
**说明**：金黄红叶、光束穿透。
**英文模板**：
```
Photorealistic autumn forest at {location}, golden and red foliage, sun rays through trees, fallen leaves, 35mm lens, f/4, warm color grading --ar 3:2
```

## 6. 田园晨雾 Pastoral Morning Mist
**说明**：乡野、薄雾、宁静治愈。
**英文模板**：
```
Photorealistic pastoral morning mist at {location}, green fields, distant farmhouse, soft fog, gentle light, 24mm lens, f/8, peaceful --ar 3:2
```

## 7. 星空银河 Starry Galaxy
**说明**：银河拱桥、地景剪影、长曝。
**英文模板**：
```
Photorealistic night sky above {location}, Milky Way arch, clear stars, dark foreground silhouette, 14mm lens, f/2.8, long exposure, low noise --ar 16:9
```

## 8. 沙漠驼影 Desert Camel
**说明**：沙丘曲线、逆光、孤寂感。
**英文模板**：
```
Photorealistic desert at {location}, rolling sand dunes, camel silhouette at golden hour, long shadows, 35mm lens, f/8, warm gradient --ar 3:2
```

## 通用负向词（Negative Prompt）
```
cartoon, anime, illustration, painting, 3d render, oversaturated, blurry, low quality, watermark, text, logo, people crowd
```
