# 文案框架库（功能 2 / 3 / 4）

本文件提供五类文案的结构模板。生成时先 **Read 用户照片**，再按所选类型套用。
可接 `qianjin-writer` 润色笔力。所有文案默认中文，配抖音/小红书标签。

---

## A. 情绪 / 治愈文案（功能 2）

**结构**：短文案（15–35 字，适配 <7 秒碎片阅读）+ 可选长叙事（2–4 句，留白、不挑对立）。

**短文案公式**：
> [场景/物] + [情绪转折] + [留白金句]

**模板**：
- 短文案：`{画面主体}，{一句温和的情绪钩子}。`
- 长叙事：`{时间/地点}拍下这张。{真实细节}。{不刻意升华的收尾}。`

**示例**（风景照）：
> 有些答案，城市给不了你，山顶可以。

**标签**：`#治愈 #摄影 #情绪文案 #风景 #日常`

---

## B. 摄影教程文案（功能 2）

**结构**：目标 → 参数 → 步骤 → 小贴士。面向想学拍照的用户，专业但说人话。

**模板**：
```
📷 怎么拍出这种【{风格}】？
▸ 器材/镜头：{如 35mm 定焦}
▸ 参数：{光圈/快门/ISO，如 f/2.8 · 1/200s · ISO200}
▸ 步骤：
  1. {机位/构图}
  2. {光线时机}
  3. {对焦/拍摄}
▸ 小贴士：{一个易错点}
```
**标签**：`#摄影教程 #手机摄影 #干货 #摄影新手`

---

## C. 审美文案（功能 2）

**结构**：专业赏析口吻，讲清「好在哪」。从构图 / 光线 / 色彩 / 情绪四维度选 2–3 个展开。

**模板**：
> 这张的妙处在【构图/光线/色彩】——{具体描述，如「三分法把视线引向远山」}。
> 【色彩】上 {如 冷调主导，留一抹暖光做对比}，克制而有层次。
> 整体是一种【情绪词】的气质，不喧哗，但站得住。

**标签**：`#审美 #摄影赏析 #构图 #光影`

---

## D. 城市记忆 / 在地文化文案（功能 3）

**输入**：照片 + 地点/景区/城市（缺则基于画面推测并标注「推测」）。
**结构**：城市切片（真实感细节）+ 在地文化钩子 + 轻量金句。

**模板**：
```
{城市/地点}的{具体位置}，藏着它最{形容词}的一面。
{真实细节：如「巷口那家开了三十年的面馆，老板娘记得每个熟客的辣度」}。
{在地文化钩子：如「这是老城区最后的柴火灶，年轻人都去新城区了」}。
{轻金句：如「一座城市的脾气，全在它肯留下来的旧东西里。}
```
**注意**：不编造具体人物故事；文化信息可查则查，不可查标注推测。
**标签**：`#城市记录 #城市切片 #中国城市 #在地文化 #摄影`

## E. 照片专业评价 + 调整建议（功能 4）

**结构**：总体印象 → 构图 → 光线 → 色彩 → 主题表达 → 改进建议。
**要求**：专业、具体、给结论（好/不足）、可操作建议。

**模板**：
```
【总体印象】{一句话定调：如「一张完成度很高的城市夜景，氛围到位」}
【构图】{如「地平线略高，主体偏下；建议下压机位让天际线更舒展」}
【光线】{如「蓝调时刻抓得好，但暗部死黑，可减曝光或提阴影」}
【色彩】{如「霓虹偏洋红，可降饱和让夜色更干净」}
【主题表达】{如「‘孤独感’传达清晰，主体孤立感成立」}
【改进建议】
  1. {机位/参数调整}
  2. {时机/后期调整}
  3. {下次可尝试}
结论：{这张值得发 / 微调后可发 / 建议重拍}
```
**标签**：`#摄影点评 #后期思路 #拍照技巧`

---

## 通用规则
- 文案不搬运网络金句，用真实细节取胜。
- 涉及他人肖像提醒用户注意授权。
- 地点/文化不可考时标注「推测」，不杜撰。
- 抖音文案短、强共鸣；小红书文案清单感、教程向。
